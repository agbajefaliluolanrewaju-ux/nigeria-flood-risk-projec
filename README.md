# Spatial Analysis of Flood Risk in Oyo Town, Oyo State, Nigeria

## Project Brief

### Spatial Question

Which areas of Oyo Town, Oyo State, Nigeria are most exposed to flood risk based on elevation, rainfall, drainage networks, and land use/land cover?

### Study Area

The study focuses on Oyo Town in Oyo State, Nigeria.

### Datasets

The project will require the following datasets:

1. **Digital Elevation Model (DEM)**  
   Source: https://earthexplorer.usgs.gov/

2. **Land Use/Land Cover**  
   Source: https://esa-worldcover.org/

3. **Rainfall Data**  
   Source: https://www.chc.ucsb.edu/data/chirps

4. **Road and Drainage Network Data**  
   Source: https://www.openstreetmap.org/

5. **Administrative Boundary Data**  
   Source: https://gadm.org/

## Project Aim

The aim of this project is to use spatial datasets and GIS techniques to identify areas of Oyo Town that may be more exposed to flooding.
